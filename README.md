### 01 / ABOUT

I'm a full-stack developer based in Morocco, building web applications,
business systems, and developer tools.

My work spans dashboards, APIs, Discord automation, and occasional
game development experiments. I like understanding how the whole
system fits together.

Some projects solve everyday problems. Others start with a question
I want to explore.
